API Reference

Types

Somoclu.Som — Type
Som(ncolumns, nrows; kwargs...)

Self-organizing map of size ncolumns × nrows.

Arguments

  • compactsupport::Bool=true: Cut off Gaussian updates beyond the training radius.
  • gridtype::String="square": "square" (legacy; hexagonal distances), "rectangular", or "hexagonal".
  • initialcodebook: Optional Matrix{Float32} of size (nDimensions, ncolumns*nrows).
  • initialization::String="random": "random" or "pca".
  • maptype::String="planar": "planar" or "toroid".
  • neighborhood::String="gaussian": "gaussian" or "bubble".
  • stdcoeff::Float32=0.5f0: Gaussian neighborhood coefficient.
  • vect_distance::String="euclidean": Feature distance for dense BMU search — "euclidean", "norm-inf", or "norm-p" with any p > 0 (e.g. "norm-1"). Sparse training requires Euclidean.
  • verbose::Integer=0: Verbosity level 0–2.
  • backend: KernelAbstractions backend (default CPU()).

Training

Somoclu.train! — Function
train!(som::Som, data; kwargs...)

Train som on data of size nDimensions × nVectors (columns are samples).

  • Dense AbstractMatrix: KernelAbstractions path (som.backend, default PoCL CPU()). BMU search uses som.vect_distance (euclidean / norm-inf / norm-p).
  • SparseMatrixCSC: C++-compatible sparse CPU kernel (ignores som.backend; codebook stays dense). Requires som.vect_distance == "euclidean".

Arguments

  • epochs::Integer=10
  • radius0::Float32=0 — 0 means min(ncolumns, nrows)/2
  • radiusN::Float32=1
  • radiuscooling::String="linear" — "linear" or "exponential"
  • scale0::Float32=0.1
  • scaleN::Float32=0.01
  • scalecooling::String="linear" — "linear" or "exponential"

Distances

Somoclu.parse_vect_distance — Function
parse_vect_distance(s) -> (kind::Symbol, p::Float32)

Parse a C++/CLI-style vector distance string: "euclidean", "norm-inf", or "norm-p" with any p > 0 (e.g. "norm-1", "norm-2.5"). Returns (:euclidean, 2), (:inf, 0), or (:p, p).

source
Somoclu.feature_distance — Function
feature_distance(codebook, neuron, data, n, nDimensions, dist_kind, p)

Host-side feature distance between codebook column neuron and data column n. dist_kind: 0 Euclidean, 1 infinity, 2 p-norm (matches denseCpuKernels.cpp).

File IO

Somoclu.read_dense_matrix — Function
read_dense_matrix(path) -> Matrix{Float32}

Read a whitespace-separated dense matrix file (or .lrn / .wts). Returns nFeatures × nSamples (Julia column-sample layout). Comment lines starting with # are skipped. .lrn / .wts % headers are parsed as in C++ readMatrix / readLrnHeader / readWtsHeader.

source
Somoclu.read_libsvm — Function
read_libsvm(path; zerobased=nothing) -> SparseMatrixCSC{Float32,Int}

Read a libsvm / sparse text file (index:value per line, optional leading label). Returns nFeatures × nSamples. If zerobased is nothing, auto-detect from indices. Matches C++ readSparseMatrixDimensions / readSparseMatrixChunk layout after converting to 1-based Julia feature rows.

source
Somoclu.write_libsvm — Function
write_libsvm(path, data::AbstractMatrix; labels=nothing, zerobased=false)

Write dense or sparse data in libsvm index:value format (1-based indices by default). data is nFeatures × nSamples.

source
Somoclu.save_codebook — Function
save_codebook(path, som::Som)
save_codebook(path, codebook, nSomX, nSomY)

Write an ESOM-style .wts codebook (%nSomY %nSomX / %nDim / weight rows). Uses internal layout nSomX = nrows, nSomY = ncolumns.

source

save_bmus(path, som::Som)

Write ESOM-style .bm best-matching units (index som_y som_x, 0-based), matching C++ saveBmus (ESOM swaps x/y in the file).

Write ESOM-style .umx U-matrix (%nSomY %nSomX then rows).

Visualization

Somoclu.view_umatrix — Function
view_umatrix(som; kwargs...) -> PlotlyLight.Plot

Plot the U-matrix (Python view_umatrix).

Keywords

  • colorscale="Spectral", reversescale=true (≈ matplotlib Spectral_r)
  • colorbar=true, bestmatches=false, bestmatchcolors=nothing, labels=nothing
  • zoom=nothing — ((row0,row1),(col0,col1)) half-open 0-based or 1-based ranges
  • figsize=nothing — (width_in, height_in) approx inches
  • filename=nothing — if set, save HTML via PlotlyLight.save
