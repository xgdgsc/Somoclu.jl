API Reference

Types

Somoclu.Som — Type
Som(ncolumns, nrows; kwargs...)

Self-organizing map of size ncolumns × nrows.

Arguments

  • compactsupport::Bool=true: Cut off Gaussian updates beyond the training radius.
  • gridtype::String="square": "square" (legacy; hexagonal distances), "rectangular", or "hexagonal".
  • initialcodebook: Optional Matrix{Float32} of size (nDimensions, ncolumns*nrows).
  • initialization::String="random": "random" or "pca".
  • maptype::String="planar": "planar" or "toroid".
  • neighborhood::String="gaussian": "gaussian" or "bubble".
  • stdcoeff::Float32=0.5f0: Gaussian neighborhood coefficient.
  • verbose::Integer=0: Verbosity level 0–2.
  • backend: KernelAbstractions backend (default CPU()).

Training

Somoclu.train! — Function
train!(som::Som, data; kwargs...)

Train som on data (nDimensions × nVectors Matrix{Float32}, or an array compatible with som.backend).

Arguments

  • epochs::Integer=10
  • radius0::Float32=0 — 0 means min(ncolumns, nrows)/2
  • radiusN::Float32=1
  • radiuscooling::String="linear" — "linear" or "exponential"
  • scale0::Float32=0.1
  • scaleN::Float32=0.01
  • scalecooling::String="linear" — "linear" or "exponential"

Somoclu.get_surface_state — Function
get_surface_state(som, data=som.data) -> Matrix{Float64}

Euclidean distances from each sample (rows) to every map neuron (columns), matching Python Somoclu.get_surface_state. data is nDimensions × nVectors.

Visualization

Somoclu.view_umatrix — Function
view_umatrix(som; kwargs...) -> PlotlyLight.Plot

Plot the U-matrix (Python view_umatrix).

Keywords

  • colorscale="Spectral", reversescale=true (≈ matplotlib Spectral_r)
  • colorbar=true, bestmatches=false, bestmatchcolors=nothing, labels=nothing
  • zoom=nothing — ((row0,row1),(col0,col1)) half-open 0-based or 1-based ranges
  • figsize=nothing — (width_in, height_in) approx inches
  • filename=nothing — if set, save HTML via PlotlyLight.save
